**Exclusions:** Duration wheels/cap, cue wheel replacement, disk persistence and new estimator formulas.

## Acceptance criteria

- [ ] Short proposed-map-leg or row tap opens one selected-leg modal before and after rejoin without shifting map/console or adding a point. While drawing with departure, proposed/original overlap offers Edit / Rejoin; after rejoin it only edits. Closing preserves geometry and partial entries.
- [ ] Magnetic heading has its own labelled section, explicit degree symbol and choices 001°–360°; first opening does not select a value.
- [ ] Heading changes and clear save independently. Done and pencil exit retain heading even if duration/cues are absent.
- [ ] Check remains inside the modal; entered and available/unavailable reference values are distinct and unchanged. Remove green per-row Check buttons.
- [ ] Manual legs show neither minute marks nor drift lines after Check; unknown/missing fields remain Not set.

- [ ] Check is available inside the modal only; remove green per-row Check. Available/unavailable references remain separate from pilot entries, preserve their values and never enable Manual minute/drift aids.
