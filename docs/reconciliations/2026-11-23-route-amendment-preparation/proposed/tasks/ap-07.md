## Outcome and scope

Moving/removing a point invalidates only affected leg values, and Undo restores the complete preparation.

Point-versus-leg gesture dispatch, direct long-press drag movement of all points including anchors, long-press release Delete, accessible Move/Delete, anchor recovery, cue retention and complete draft Undo.

**Exclusions:** Flight Undo (#210), recorded flight history, Assisted recalculation implementation and active flown-route editing.

## Acceptance criteria

- [ ] Long-press drag moves any point including departure/rejoin; release without dragging offers Delete. Anchor drops satisfy eligible original-route/order constraints and invalid drops roll back with feedback. Short proposed-leg/row taps edit values including while drawing.
- [ ] Moving a via point clears heading/time only on its adjacent changed Manual legs; unchanged leg entries remain.
- [ ] Moving geometry retains cues on surviving logical edges. Removing a point deletes removed-edge cues; the new merged edge begins empty.
- [ ] Undo restores points, rejoin/departure, selection, required/partial values and cues together.
- [ ] Rejected edits leave the prior draft intact; only explicit corrections change anchors. No operational route/event mutation occurs.

- [ ] Deleting departure retains vias/rejoin and unaffected values, marks geometry incomplete, and next eligible route tap replaces departure. Deleting rejoin explicitly reopens drawing from last surviving point until eligible return. Missing anchors block Arm; Undo restores the complete draft.
- [ ] Map tools provides waypoint/map-center placement and native named Departure / Point N / Rejoin actions with Move / Delete. Accessible Move uses next eligible-location tap, applying the same validation/rollback/Undo without a plotting toggle.
