# AP-10 · Warn when pilot progression passes an unarmed departure

**Status:** approved contract · John · 2026-11-24. Publication authorized; implementation remains separately requested.

**Requirements:** G05, G02. **Planned tracker:** GitHub johnbenz13/NavigationFlight.

## Outcome and scope

A pilot gets one clear warning, retains other work and can choose a new departure before Arm.

Unarmed departure eligibility invalidation, contextual alert, persistent warning and Update departure/Later handling.

**Exclusions:** Armed missed-departure redesign, GPS advancement and flight execution/rejoin changes.

## Acceptance criteria

- [ ] Pilot-reported progress past the unarmed departure marks it unavailable without deleting intermediate points, rejoin or unaffected values.
- [ ] Show the alert once per invalidation, immediately in Cockpit or on return to it; Later leaves persistent warning and disabled Arm.
- [ ] Update departure enters an explicit eligible-anchor selection; preserve the draft while choosing/cancelling.
- [ ] Replacing departure clears values only for changed geometry, restores eligibility when valid and does not automatically arm.
- [ ] Pencil exit remains available; elapsed time, GPS and passive map use never trigger invalidation or warning. Armed missed-departure behavior stays existing.
