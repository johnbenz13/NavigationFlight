## Acceptance criteria

- [ ] Entry is plotting-off. Plot points first chooses an eligible departure, then adds existing/free waypoints and rows.
- [ ] Rows exist while route is incomplete, with independent missing-value presentation and no operational-route mutation.
- [ ] Done plotting permits leg selection/value editing before rejoin; returning to plotting is explicit.
- [ ] Plotting map taps do not open a value editor; plotting-off taps do not accidentally add points. Pan/zoom remains available.
- [ ] Preserve final destination, reject consecutive duplicate coordinates and keep existing accessible map-center/occurrence input routes.
