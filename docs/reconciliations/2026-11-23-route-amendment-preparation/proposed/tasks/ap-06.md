## Outcome and scope

The pilot can add or clear optional advisory cues without making them required for Arm.

Optional cue disclosure, altitude/frequency wheel replacement and retained note entry. Preserve existing off-step values.

**Exclusions:** 8.33 kHz, actual radio tuning, new in-flight cue semantics and new identification targets.

## Acceptance criteria

- [ ] Altitude offers −1,500…20,000 ft MSL in 100 ft steps; use explicit units and Not set/clear.
- [ ] Radio offers only 118.000…136.975 MHz valid 25 kHz channels. MHz/fractional wheels cannot construct invalid combinations; 8.33 kHz is deferred.
- [ ] Existing out-of-range/off-step cues stay visible and unchanged until deliberately edited; there is no silent rounding or forced clearing.
- [ ] Visual-reference note uses existing native text entry. Keep active field and Done reachable with the keyboard and Larger Text.
- [ ] Omitted cues do not prevent readiness or generate timed identification/navigation events; entering a cue does not overwrite heading/time.
