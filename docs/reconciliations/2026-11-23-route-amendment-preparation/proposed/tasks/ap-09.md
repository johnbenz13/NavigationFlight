# AP-09 · Recover an unfinished draft with its Flight

**Status:** draft contract; awaiting breakdown approval. Not published or authorized for implementation.

**Requirements:** G05, G01, Q36. **Planned tracker:** GitHub johnbenz13/NavigationFlight.

## Outcome and scope

A pilot can leave or restart and recover the same unfinished work, with honest save-failure status.

Versioned Flight-keyed draft persistence, lossless partial/selection/Undo recovery, save retry and confirmed unarmed discard.

**Exclusions:** Changing operational recording schemas or recovery policy; treating an unarmed draft as a navigation event.

## Acceptance criteria

- [ ] Persist route, partial values, cues, captured mode/provenance, selection/editor context and Undo snapshots after work begins. Untouched exit stores nothing.
- [ ] Recover only with the same unfinished Flight, into ordinary Cockpit, plotting off and unarmed; preserve existing armed recovery.
- [ ] A failed save shows unsaved status and Retry without blocking pencil exit; latest in-memory draft survives. No false claim of restart durability.
- [ ] Confirmed unarmed discard removes the stored draft and returns to Cockpit; cancelled discard retains it. Failed deletion does not claim completion.
- [ ] Never carry data into another/closed/deleted Flight; unsupported/corrupt data is preserved without arming or overwriting, with scoped failure status.
- [ ] Draft saves do not add operational journal events or change captured plans/GPX/evidence exports.
