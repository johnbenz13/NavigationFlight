Point-versus-leg hit dispatch, explicit Move placement, Remove, new departure/return corrections, cue retention and full draft Undo.

## Acceptance criteria

- [ ] Plotting-off waypoint tap exposes Move/Remove; leg or row tap edits values. Move requires a deliberate placement action.
- [ ] Moving a via point clears heading/time only on its adjacent changed Manual legs; unchanged leg entries remain.
- [ ] Moving geometry retains cues on surviving logical edges. Removing a point deletes removed-edge cues; the new merged edge begins empty.
- [ ] Undo restores points, rejoin/departure, selection, required/partial values and cues together.
- [ ] Rejected edits leave the prior draft intact; only explicit corrections change anchors. No operational route/event mutation occurs.
