## Acceptance criteria

- [ ] Leg time is visually separated from Magnetic heading; Minutes and Seconds form one section.
- [ ] Allow 00–60 minutes and 00–59 seconds, capped at 60:00. At minute 60 seconds is limited to 00; never silently accept more than 60:00.
- [ ] 00:00 remains invalid and prevents readiness. Untouched time stays Not set; preserve partial editing state through Done/pencil exit.
- [ ] Updating time does not overwrite heading or optional cues; all rows/readiness use the same validation.
- [ ] Keep the first-edit/clear semantics explicit in the approved contract; no wheel-centre default is accepted merely by opening.
