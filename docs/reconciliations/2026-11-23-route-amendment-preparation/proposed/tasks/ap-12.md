## Acceptance criteria

- [ ] Armed values/geometry are read-only. Disarm and edit restores the preceding operational route durably before enabling edits, preserving the preparation.
- [ ] Disarm and discard asks explicitly; cancellation retains Armed, successful reversal/deletion returns to Cockpit, and failure preserves last committed state with Retry.
- [ ] Awaiting Manual Start leg remains grey with its explanation. First replacement leg start makes Flying green, using existing progression signals.
- [ ] Flying pencil opens read-only route/value inspection; no further amendment editing/replacement is introduced here.
- [ ] No Start now, pause/resume or new operational cockpit design appears. Normal flight actions, timer, target, checklist, revisions and existing missed-departure handling remain unchanged.
